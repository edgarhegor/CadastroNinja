# Sistema de Cadastro de Ninjas 🥷

Projeto desenvolvido em Java com foco em prática de lógica de programação e manipulação de arrays.

O sistema funciona via terminal e permite realizar operações básicas de gerenciamento de ninjas, simulando um pequeno CRUD sem utilização de banco de dados.

## Funcionalidades

* Cadastro de ninjas
* Listagem de ninjas cadastrados
* Edição de ninjas existentes
* Remoção de ninjas
* Menu interativo no terminal
* Validação de posições do array

## Conceitos praticados

Durante o desenvolvimento deste projeto foram utilizados conceitos fundamentais da linguagem Java, como:

* Tipos de dados
* Arrays
* Estruturas condicionais (`if/else`)
* Estruturas de repetição (`for` e `while`)
* Entrada de dados com `Scanner`
* Manipulação de índices
* Controle de fluxo
* Lógica de programação

## Objetivo do projeto

O objetivo principal deste projeto foi praticar lógica de programação e estrutura de dados básicas utilizando Java puro, sem frameworks ou banco de dados.

## Tecnologias utilizadas

* Java
* IntelliJ IDEA
